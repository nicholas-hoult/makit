Why makit

An AI coding session is a conversation that lives in a terminal window. Close the window, rename the folder, restart the Mac, and the conversation is still on disk, but nothing points at it any more. makit changes the unit: the session is the object, not the window. It reads the session files Claude Code and Codex already write, so every session is listed whichever terminal it was started in.

What it does

  • Never lose a sessionScans ~/.claude and ~/.codex, groups by project or state, and searches across all of them. Sessions started in any terminal show up.
  • Know who is waitingA state dot on every session, and a desktop notification when one needs approval or an answer (Claude Code, hook installed from Settings).
  • Pick up where you left offResume in the original directory. If it was deleted or moved, makit rebuilds the link so a Claude Code session is not lost.
  • Read it back, reflowedExperimental, off by default. History is re-laid out from the session file as you resize; the live part stays a real terminal.
  • Split terminalsTree-style splits you resize by dragging, to keep an eye on several sessions.
  • Local and privateReads session files on your machine. No account, no telemetry, nothing uploaded.
  • Native and lightRust + GPUI, not a wrapped web page. About 55–75 MB of memory, 5,000 sessions listed in under a second.
  • 21 themes, English / 中文Themes follow the system light / dark setting; iTerm2 colour schemes can be imported.
  • Updates built inChecks for a new version and replaces itself in place, or brew upgrade if you installed with Homebrew.

Download for Windows

First launch: this build is not signed by Apple, so macOS stops it once. Open System Settings → Privacy & Security and click Open Anyway; if it says the app is damaged, run xattr -dr com.apple.quarantine /Applications/makit.app. Updates downloaded inside the app are not blocked again.

FAQ

How is this different from a terminal or a multiplexer?

makit does include split terminals, but it is organised around sessions, not windows: it lists sessions started anywhere, keeps their history, and tells you which one is waiting. Use it alongside the terminal you like.

Which agents are supported?

Claude Code and Codex. Status and notifications are Claude Code only for now; Codex sessions can be listed and resumed.

Does it upload my sessions?

No. It reads local files. The update check only requests version information; nothing about your sessions, paths or projects is sent.

What does it read and write on my machine?

It reads ~/.claude/projects, ~/.claude/sessions and ~/.codex/sessions. Its own data is in ~/.claude/makit. It touches ~/.claude/settings.json only when you click “Install hook”. The README lists everything.

If I delete makit, do I lose my sessions?

No. The sessions belong to Claude Code and Codex and stay where they are. Deleting ~/.claude/makit only removes makit’s own settings and archive marks.

Why is it not signed?

There is no Apple developer account yet. The steps to allow it on first launch are in “Install”. Updates downloaded inside the app are not blocked again.

Windows and Linux?

Windows has a preview build from 0.1.5 (it runs, but some features are placeholders). Linux is planned for 0.3.
