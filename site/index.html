Why makit

An AI coding session is a conversation that lives in a terminal window. Close the window, rename the folder, restart the Mac, and the conversation is still on disk, but nothing points at it any more. makit changes the unit: the session is the object, not the window. It reads the session files Claude Code and Codex already write, so every session is listed whichever terminal it was started in.

What it does

Never lose a session

Scans ~/.claude and ~/.codex, groups by project or state, searches across all of them. Sessions started in any terminal show up. Nothing to migrate, nothing uploaded.

Know who is waiting

A state dot on every session and a desktop notification when one needs approval or an answer (Claude Code, hook installed from Settings).

Pick up where you left off

Resume in the original directory. If it was deleted or moved, makit rebuilds the link so a Claude Code session is not lost.

Read it back, reflowed

Experimental, off by default. History re-laid out from the session file as you resize; the live part stays a real terminal.

Split terminals

Tree-style splits you resize by dragging, to keep an eye on several sessions.

Install

macOS only for now (0.1); Windows is planned for 0.2 and Linux for 0.3.

Download

Download the .dmg, open it and drag makit into Applications.

Download for macOS

Homebrew

brew install --cask nicholas-hoult/tap/makit
First launch: this build is not signed by Apple, so macOS stops it once. Open System Settings → Privacy & Security and click Open Anyway; if it says the app is damaged, run xattr -dr com.apple.quarantine /Applications/makit.app. Updates downloaded inside the app are not blocked again.
