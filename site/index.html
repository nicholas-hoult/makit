All your AI coding sessions,
in one window

makit is a native macOS app (Rust + GPUI, not an Electron wrapper) that manages your local Claude Code and Codex sessions: browse, resume, split terminals, live status.

Download for macOS View on GitHub

Universal package (Intel + Apple Silicon), about 15 MB · latest v0.1 · unsigned: allow it manually on first launch

What it solves

Three projects, each with an AI session attached. A is waiting for you to approve a refactor, B just finished its tests, C's bug is still being fixed. Telling them apart means opening every window. makit puts that on one screen.

Session list

Scans the sessions already on your machine, groups them by project and shows running / waiting for approval / idle / stopped / archived.

One-click resume

Pick a past session and keep going in its original directory; Claude Code sessions can be rescued even if the directory was deleted.

Split terminals

Tree-style splits you resize by dragging: one screen to keep an eye on several sessions.

Status notifications

A desktop notification when a session is waiting for you, so you do not have to watch the window (Claude Code).

Why makit

Light

Pure Rust + GPUI native rendering. 7.7 MB installer (single architecture), about 15 MB universal.

Fast

Session list ready in about 0.6–0.9 s with 5,000 sessions; memory around 55–75 MB; appending to a long conversation is constant time.

Beautiful

21 curated themes that follow the system light / dark setting, and iTerm2 .itermcolors import.

Chinese / English

English by default; switch to Chinese or follow the system in Settings, effective immediately.

Install

macOS only for now (0.1); Windows is planned for 0.2 and Linux for 0.3.

Download

Download the .dmg, open it and drag makit into Applications.

Download for macOS

Homebrew

brew install --cask nicholas-hoult/tap/makit
First launch: this build is not signed by Apple, so macOS stops it once. Open System Settings → Privacy & Security and click Open Anyway; if it says the app is damaged, run xattr -dr com.apple.quarantine /Applications/makit.app. Updates downloaded inside the app are not blocked again.

Performance
