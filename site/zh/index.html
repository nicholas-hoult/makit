makit 是一个原生的 macOS 应用（Rust + GPUI，不是 Electron 套壳），管理本机的 Claude Code 和 Codex 会话：浏览、恢复、分屏终端、实时状态。

下载 macOS 版 在 GitHub 查看

通用包（Intel + Apple Silicon），约 15 MB · 当前版本 v0.1 · 未签名，首次打开需手动放行

它解决什么

三个项目各挂着一个 AI 会话：A 在等你批准重构，B 刚跑完测试，C 的 bug 还在修。终端窗口散落各处，想知道谁还活着、谁在等你，只能一个个点开看。makit 把这件事放到一个界面里。

会话列表

扫描本机已有的会话，按项目分组，显示运行中 / 等待审批 / 空闲 / 已停止 / 已归档。

一键恢复

选一个过去的会话接着聊，回到原来的工作目录；Claude Code 会话即使原目录被删也能救回。

分屏终端

树形分屏，拖动调整大小，一个屏幕盯住多个会话。

状态通知

会话在等你时弹桌面通知，不用盯着窗口（Claude Code）。

为什么是它

轻

纯 Rust + GPUI 原生绘制。单架构安装包 7.7 MB，通用包约 15 MB。

快

5000 个会话时会话列表约 0.6–0.9 秒就绪；内存约 55–75 MB；长对话里每新增一条记录是常数时间。

好看

21 套精选主题，自动跟随系统深 / 浅色，可直接导入 iTerm2 的 .itermcolors。

中文 / English

界面默认英文，设置里可切换成中文或跟随系统，即时生效。

主题

安装

目前只有 macOS（0.1）；Windows 计划 0.2，Linux 计划 0.3。

下载安装包

下载 .dmg，打开后把 makit 拖进「应用程序」。

下载 macOS 版

Homebrew

brew install --cask nicholas-hoult/tap/makit
第一次打开：这个包还没有 Apple 签名，macOS 会拦一下。到 系统设置 → 隐私与安全性 点 仍要打开；如果提示「已损坏」，在终端运行 xattr -dr com.apple.quarantine /Applications/makit.app。应用内更新下载的文件不会再被拦。

性能

合成会话，Intel Core i7-1068NG7，release 构建，单架构。完整数据、方法和限制见 README。

指标数值
安装包（.dmg，单架构）7.7 MB
5,000 个会话，会话列表就绪0.6–0.9 s
运行内存55–75 MB
长对话每新增一条记录（5–200 MB）≈ 0.04 ms
只读你本机的会话文件。检查更新时只请求版本信息，不会上传任何会话内容、路径或项目名。
